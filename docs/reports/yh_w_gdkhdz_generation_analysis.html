银河证券 w 版柜台 — 股东客户对照生成 SQL 分析

类型：单条导出 SQL（MSSQL / run 库） 输出格式：新意股东客户对照（XY_GDKHDZ） 共 6 个 SELECT 段（5 个 UNION ALL） 文件：银河证券w版股东客户对照生成.sql

该脚本在银河证券 w 版柜台（run 库）中直接以 SQL 方式生成股东客户对照数据，输出列 JYPZ / GDZH / ZDXW / JGDM / YYBDM / ZJZH / YHDM / CGFS / ZHZT / JYZH， 与 MACBS 侧 node_gdkhdz 表（新意 XY_GDKHDZ 导出格式）的 10 个业务列完全对应， 是柜台侧直接出数、替代服务端生成的方案。其核心基于大集中柜台的 secuid / fundinfo / banktranid / dictvalue / orgidset / oftaaccinfo / oftaacc / ofta / rptselfrunsecuid 九张表，按股东与基金两条主线、四个业务分支输出对照记录。

5.3 银行代码转换（Fsftoxy 字典）

柜台三方存管银行代码 → 新意银行代码，统一走 dictvalue 字典： dictitem='Fsftoxy'，subitem=柜台bankcode，取 subitemname 作为输出 YHDM。 转换失败（无字典记录）时 join 不命中，等价于"无银行"，输出 9998。

⚠️ 与 MACBS 的差异：MACBS 无银行时输出 9999 或空格，且允许通过 cgfs 配置过滤非三方存管记录；w 版无银行统一输出 9998，不提供过滤能力。

六、关键业务规则要点

  • S 类资金分流（段1/2 ↔ 段5/6 互补）：A股类市场（0/1/5/6/S）的股东要求资金账户 specialkind 含 'S'（特殊资金）才在段1/2 输出并携带三方存管银行关系；非 S 类资金的 A股 股东（0/1/6/B）由段5/6 兜底输出，不带银行（YHDM=9998、CGFS=0）。B股类（2/3/7）及基金 J 股东不受 S 类限制，均走段1。
  • 京A/股转A 双挂排除：同一 serverid+orgid+secuid 同时存在 market='6'（股转A）与 market='B'（京A）时，股转A 优先输出、京A 被排除（段2/段6 均带此排除条件），避免同一股东代码对照重复。
  • 自运行股东排除：凡在 rptselfrunsecuid 中（selfrunsecuid 或 secuid 匹配 + market 匹配）且 bsflag IN ('1N','1O') 的股东全部不输出——该类属自运行交收（不参与统一清算结算）。
  • 沪港通/深港通（5/S）只随 S 类资金输出：非 S 类资金的沪港通/深港通股东既不在段1（被 specialkind 条件过滤）也不在段5（市场范围仅 0/1/6/B），最终不输出。
  • 沪A 指定交易开关恒真：a.regflag <> '0' OR '1'='1' 中 '1'='1' 恒真，当前沪A 股东全部输出；该写法保留"仅输出指定交易股东"的开关位（改为 '1'='0' 即启用 regflag 过滤）。
  • 资金类型限定：仅 fundtype in ('', 'A', 'B') 的资金账户参与；其他类型（如信用类）不生成对照。
  • 市场↔S类资金匹配：段5/6 额外按客户维度排除（custid NOT IN 含S类资金的客户），与段1/2 的按资金维度判断殊途同归，确保同一记录不跨段重复输出。
  • 银行关系限定人民币三方存管：banktranid 只取 moneytype='0'（人民币）且 status<>'*'，外币银行不参与 YHDM 输出（B股 固定 9998）。
  • 基金 TA 无银行兜底：段4 输出"无三方存管"的基金 TA 记录（GDZH 生成值非空），保证基金客户对照不遗漏。

九、完整 SQL（整理后）

-- ============ 段1：非京A 股东（S类/B股/基金J 市场） ============
SELECT
  JYPZ = CASE
    WHEN ISNULL(m.market,'')='0'  THEN 'SAGF'   -- 深A
    WHEN ISNULL(m.market,'')='1'  THEN 'HAGF'   -- 沪A
    WHEN ISNULL(m.market,'')='2'  THEN 'SBGF'   -- 深B
    WHEN ISNULL(m.market,'')='3'  THEN 'HBGF'   -- 沪B
